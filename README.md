# peer_relationship_chart
Peer relationship analysis and smart kindergarten management system for Smart Childcare Centers

## Overview
**Peer Relationship Chart** is a visualization and management tool designed to analyze peer-to-peer relationships within kindergarten and childcare environments.  
It helps supervisors understand emotional/social connections between children and supports decision-making for child development, class management, and personalized care.

## Objective
Enable **peer relationship analysis** and enhance **smart kindergarten management** by:
- Mapping relationships between children  
- Improving class management and grouping decisions  
- Supporting supervisors through clear, data-driven insights  
- Integrating modern tools into on-site childcare centers

## Key Contributions (Implemented)
- **Designed and implemented a supervisor dashboard**  
  - Provides an interface for viewing, editing, and analyzing peer relationships  
  - Supports monitoring class-level data and visual insights  

- **Implemented Bulk CRUD for classes and peer data**  
  - Sends bulk create/update/delete requests to the backend server  
  - Enables efficient data management for large student groups  

- **Participated in Smart Childcare Center model demonstration**  
  - Supported real-world testing and demonstration  
  - Collaborated in evaluating practical use scenarios for childcare professionals
